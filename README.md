# 智能汽车侧面轮廓感性生成系统

[打开在线应用](https://abdd33.github.io/car-profile-studio/)

调整四个感性目标，或选择预设，点击「开始优化」。在帕累托图中选择一个点，再点击「更新预览界面」，即可查看该方案的轮廓、尺寸和风阻系数预测。支持 2D 与 3D 预览，以及 PNG、DXF、Rhino 3DM 导出。CAD 文件使用米为单位。

## 计算方式

五个预测模型由原项目的 MATLAB 训练脚本和数据导出。风阻系数采用 ARD Matérn 5/2 高斯过程回归，四项感性评分采用标准化线性支持向量回归。左侧顶线使用 PCHIP 插值，右侧使用三次样条插值。

浏览器通过 Web Worker 运行多目标进化搜索，种群规模为 200，迭代 50 代。目标和约束沿用原项目。网页版自行实现选择、交叉和变异，因此每次搜索的帕累托方案可能与 MATLAB 的 `gamultiobj` 不同。界面的 Wheelbase 数值沿用原模型的底盘端点跨度计算。

## 本地运行

在仓库根目录执行 `python -m http.server 8000`，然后打开 `http://localhost:8000/`。网站的模型、样式、3D 渲染与 CAD 导出依赖均随仓库提供。

## 发布

GitHub Pages 从 `main` 分支的根目录发布。更新静态文件并推送到该分支后，GitHub 会重新发布网站。
